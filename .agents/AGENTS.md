# Reglas del Proyecto (GOLDTEX)

- **No usar Emojis en la UI**: Está estrictamente prohibido usar emojis en los textos de botones, badges, modales o cualquier parte de la interfaz de usuario (ej. no usar "✏️", "🌐", etc.). En su lugar, utiliza íconos de Lucide o SVG acordes al diseño limpio de la aplicación.
- **Prohibición de Diálogos Nativos**: Queda estrictamente prohibido usar 'window.confirm()', 'window.alert()' o 'window.prompt()'. Todas las confirmaciones y advertencias deben renderizarse mediante componentes Modal o Dialog personalizados en Tailwind CSS.
- **Prevención de Pérdida de Datos**: Cualquier formulario o matriz (ej. Permisos, Ajustes) que tenga cambios sin guardar (estado 'isDirty' o 'hasChanges') debe interceptar la navegación. Si el usuario intenta cambiar de pestaña interna o de ruta, el sistema debe bloquear la acción y mostrar un Modal de Advertencia personalizado en Tailwind CSS preguntando si desea descartar los cambios o quedarse a guardar.
- **Prohibición de Borrado Físico (Soft Delete Obligatorio)**: Queda estrictamente prohibido ejecutar consultas 'DELETE FROM' (borrado físico) sobre tablas de entidad primaria ('roles', 'profiles', 'employees', 'stores', 'products', 'clients', 'sales'). Toda eliminación debe ser un Borrado Lógico (Soft Delete) mediante 'UPDATE ... SET is_active = false' o 'deleted_at = NOW()'. Los selectores y vistas del sistema deben filtrar automáticamente 'WHERE is_active = true'.
